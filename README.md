# FitTrack

Учебный справочник упражнений и тренировочных комплексов на Python, PyQt6 и SQLite.
Сейчас готово первое окно: поиск, шесть категорий и обычный список упражнений.
Поиск работает по названию, категории и оборудованию. Кнопка «Все упражнения» сбрасывает фильтры.
Данные пока демонстрационные. Изображения, база данных и страницы упражнений будут добавлены следующими шагами.

## Открыть проект в PyCharm

Открой папку `/Users/therain/Developer/FitTrack` как существующий проект.
Выбери существующий интерпретатор `.venv/bin/python` внутри этой папки.
Запускай файл `main.py`.

## Редактировать дизайн отдельно

Дважды нажми `Открыть дизайн.command` в Finder. Он откроет `ui/main_window.ui` в отдельном Qt Designer.
Сохраняй изменения в том же файле. При следующем запуске `main.py` приложение загрузит обновлённый дизайн.

`Qt Designer.app` открывает редактор отдельно. Другой файл `.ui` можно выбрать через меню File → Open.

## Запустить приложение

Дважды нажми `Запустить FitTrack.command` в Finder либо запусти `main.py` из PyCharm.
Главное окно имеет начальный размер 1000 × 900. Элементы расставлены вручную и не перестраиваются при изменении размера окна.
Длинный список упражнений можно прокручивать.

## Зависимости

Приложение использует PyQt6 из `requirements.txt`.
Для редактора установлен PySide6 из `requirements-designer.txt`.
Оба пакета установлены в `.venv` проекта и запускаются отдельными процессами.

Каталог `assets/exercises` подготовлен для GIF упражнений, `assets/icons` — для иконок.

## Изменять первое окно в Qt Designer

Открой `ui/main_window.ui`. Все элементы созданы стандартными виджетами Qt и доступны в Object Inspector.
Компоновщиков, распорок и ограничений минимального или максимального размера нет.
Элементы можно свободно перетаскивать мышью. Их положение и размер задаются в свойстве `geometry` — `x`, `y`, `width`, `height`.
Цвета и размеры шрифтов находятся в свойстве `styleSheet` главного окна.
Иконки и дополнительные ресурсы в упрощённом окне не используются.

## Какие файлы читать

`ui/main_window.ui` — 306 строк: расположение элементов, их подписи и оформление.
Комментарии делят его на заголовок, поиск, категории, список и подсказки.

`main.py` — 88 строк: примеры упражнений, подключение кнопок, поиск и запуск окна.
В списке `self.exercises` у каждого упражнения три значения: название, категория, оборудование.
Метод `filter_exercises` обновляет список на экране, а `show_all_exercises` сбрасывает фильтры.

На главной странице показаны два примера, кнопка «Все упражнения» показывает все шесть.
Вместо повторяющихся карточек используется один стандартный `QListWidget`.
